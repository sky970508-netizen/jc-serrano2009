# 저널클럽: 복잡 가중 네트워크의 다중스케일 백본 추출

Serrano MÁ, Boguñá M, Vespignani A (2009)
*Extracting the multiscale backbone of complex weighted networks.*
**PNAS** 106(16):6483–6488. [doi:10.1073/pnas.0808904106](https://doi.org/10.1073/pnas.0808904106)

원문과 한국어 번역을 문단 단위로 교차 배치한 읽기용 페이지입니다.

👉 **<https://sky970508-netizen.github.io/jc-serrano2009/>**

## 보는 법

| | |
|---|---|
| 보기 모드 | `교차` / `2단` / `한글` / `English` — 단축키 `1` `2` `3` `4` |
| 이동 | 좌측 목차, `J` / `K` 로 섹션 단위 이동 |
| 그림 | 클릭하면 전체화면, 한 번 더 클릭하면 원본 크기 |
| 기타 | `T` 다크모드, `+` / `−` 글자 크기, `?` 단축키 전체 |

`index.html` 한 파일로 완결되어 있습니다 — 그림과 수식 폰트(KaTeX)가 모두 내장되어 있어 파일을 내려받으면 오프라인에서도 그대로 열립니다.
